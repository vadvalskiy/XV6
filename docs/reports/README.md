# Laboratory reports

This directory contains the complete submitted report for each project phase in two forms:

- `report.fa.md`: editable Persian source with document metadata;
- `report.fa.pdf`: final rendered report retained as an official review artifact.

The PDFs are committed intentionally because they are the final submitted artifacts, while the Markdown files provide an auditable and searchable source. Report claims are classified in [`VERIFICATION.md`](../VERIFICATION.md); historical observations are not automatically treated as newly reproduced runtime evidence.
