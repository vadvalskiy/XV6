# Laboratory phase index

The repository contains one cumulative xv6/x86 implementation. The four laboratory phases are represented by Git history and milestone tags rather than duplicate source trees.

| Phase | Scope | Milestone tag | Report | Assignment |
| --- | --- | --- | --- | --- |
| Lab 1 | xv6 foundations, boot path, GDB, console editing, and `find_sum` | `lab1-complete` | [`reports/lab-01/`](../../reports/lab-01/) | [`docs/assignments/lab-01/`](../assignments/lab-01/) |
| Lab 2 | system calls, pseudo-random numbers, process inspection, and sorting | `lab2-complete` | [`reports/lab-02/`](../../reports/lab-02/) | [`docs/assignments/lab-02/`](../assignments/lab-02/) |
| Lab 3 | multilevel scheduling, WRR, SJF, FCFS, accounting, and aging | `lab3-complete` | [`reports/lab-03/`](../../reports/lab-03/) | [`docs/assignments/lab-03/`](../assignments/lab-03/) |
| Lab 4 | syscall counters, producer-consumer, reader-writer locks, and ticket locks | `lab4-complete` | [`reports/lab-04/`](../../reports/lab-04/) | [`docs/assignments/lab-04/`](../assignments/lab-04/) |

The original delivery archive contained four full `source/` snapshots and locally generated build products. Those redundant copies are intentionally not tracked here. The final cumulative implementation is in `xv6/`, while the complete reports and assignment specifications are retained in dedicated directories.
