## Recommended controls

- require the `CI` workflow before merging to `main`;
- require pull requests for collaborative changes;
- disallow force pushes and branch deletion on `main`;
- enable vulnerability alerts only as an informational aid—the project is not production software;
- use Releases for generated images or benchmark logs instead of committing them;
- keep Issues enabled for reproducible defects and documentation corrections;
- do not enable GitHub Pages unless a separate documentation site is intentionally maintained.
