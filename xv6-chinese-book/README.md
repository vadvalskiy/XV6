# xv6 Chinese Book

This directory contains the source files for a Chinese translation and explanation of the xv6 operating system.

## Structure

The book is organized into chapters, with each chapter in its own directory (e.g., `chapter-01-introduction`). 
Within each chapter directory, individual sections are stored in separate Markdown files (e.g., `section-1-1.md`).

Please contribute by filling in the content for these section files.
